## 一、本次强化完成的端到端真实交互后果

彻底废除仅依赖区域像素变化或色值差异冒充交互成功的做法，所有菜单、命令面板与设置弹窗均通过真实物理操作并断言可观察业务后果：

### 1. 菜单真实交互后果（全选 → 呼出 ContextFlyout → 键盘执行「剪切」→ 检验草稿清空与剪贴板）
- **操作链路**：
  1. 在已聚焦的输入框内执行全选（`Ctrl+A`）；
  2. 右键点击输入框唤起 Avalonia 文本框 ContextFlyout (`MenuFlyoutPresenter`)；
  3. 留存 `smoke-menu-font.png` 截图供人工核验弹出层中文字体；
  4. 按键盘 `ArrowDown` 聚焦第一项「剪切」，按 `Enter` 执行剪切操作；
  5. **断言真实草稿后果**：文本已被剪切清空，IndexedDB `wanxiang-drafts` 快照记录实时变为空串（`readDraftRaw() === ''`）；
  6. 通过 `Ctrl+V` 粘贴将内容恢复，保证后续流程基线确定；
  7. 再次右键呼出菜单并按 `Escape`，断言 Esc 级联退栈且输入框重新获得物理焦点（`bridgeFocused()`）。
- **证明与边界区分**：
  - 机器断言证明的是**菜单真实挂载并成功触发了「剪切」操作，产生了真实的清空草稿后果与 Esc 焦点退栈**；
  - 机器断言**不能**代替字体肉眼走查；弹出层内的「剪切」「复制」「粘贴」中文呈现必须由人工查看 `smoke-menu-font.png` 确认无豆腐块。

### 2. 命令面板真实交互后果（过滤输入 → 回车执行特定命令 → 检验持久化记录）
- **操作链路**：
  1. 按下 `Ctrl+K` 呼出命令面板弹窗；
  2. 在搜索框中键盘键入过滤词 `"theme"`（精确匹配切换主题命令）；
  3. 留存 `smoke-palette.png` 截图；
  4. 按键盘 `Enter` 执行选中的第一项命令（`act:theme`）；
  5. **断言真实业务后果**：
     - 命令面板遮罩与弹窗自动关闭；
     - 宿主执行命令后将所选条目记入「最近使用」，`localStorage["wanxiang.local:palette-recent.json"]` 内确定性新增 `"act:theme"` 记录。
- **证明与边界区分**：
  - 机器断言证明的是**命令面板弹窗响应了真实键盘过滤，回车执行了特定命令并完成了持久化**；
  - 面板各条目的中文字形与高亮样式需通过核验 `smoke-palette.png` 确认。

### 3. 设置弹窗真实交互后果（呼出设置页 → 切换分区 → 翻转偏好开关 → 检验 localStorage 实时持久化）
- **操作链路**：
  1. 按下 `Ctrl+,` 打开设置大弹窗；
  2. 留存 `smoke-settings.png` 截图；
  3. 点击左侧导航栏「界面外观」标签（`buttons["appearance"]`）；
  4. 在外观分区卡片中，对开关行（如 `enterSends`）进行物理点击；
  5. **断言真实业务后果**：
     - `Ui.switchRow` 响应点击并触发 `hooks().SavePrefs`，`localStorage["wanxiang.local:ui.json"]` 内的偏好值实时由 `true` 翻转为 `false`；
     - 再次点击恢复初始配置；
  6. 按下 `Escape` 关闭设置页，断言大面板退栈关闭，工作区恢复且输入框重新获得物理焦点。
- **证明与边界区分**：
  - 机器断言证明的是**设置大面板真实挂载、分区切换有效、开关操作真实修改了偏好并完成持久化，且 Esc 成功退栈回焦**；
  - 各分区标题与提示文案中文正确性需通过核验 `smoke-settings.png` 确认。

### 4. 主题轮转与物理亮度对比（明暗切换与偏好持久化）
- **操作链路**：
  1. 按下 `Ctrl+Shift+S` 触发主题轮转；
  2. 断言 `localStorage["wanxiang.local:ui.json"]` 内 `theme` 键变更为 `"dark"`；
  3. 全屏采样平均亮度断言深色模式物理亮度 < 100（浅色模式 > 140）；
  4. 留存 `smoke-theme-dark.png` 与 `smoke-theme-light.png` 截图。
- **严禁以亮度差宣称语义正确**：
  - 物理亮度差仅证明调色板暗色系生效；
  - 局部组件文字对比度与无反色缺陷，必须由人工走查深色截图及 `A11yRegression.fs` 静态门禁把关。
