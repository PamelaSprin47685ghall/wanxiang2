# Avalonia 控件类型清单（外部 API 的快照，不是仓库事实）
#
# 用途：./x check 判定「什么算一个控件库」——见根 AGENTS.md §5《控件库交付约定（沿用）》。
# 判据：libs/<Name>/ 的生产源码（不含 tests/、obj/、bin/）里构造了清单中至少一个类型，
#       即为控件库；每个控件库在 compose/Gallery 至少有一条条目。
#
# 重新生成（清单随 Avalonia 版本变化，升级 Avalonia 后要重新取一次）：
#   dotnet script / 用 dotnet fsi 载入 Avalonia.Controls 程序集，枚举所有继承自
#   Avalonia.Controls.Control 的具体类型，取类型名，逐行写出。
#   参考：https://api.nuget.org/packages/Avalonia/12.1.2
#
# 每行一个类型名；# 开头是注释。
